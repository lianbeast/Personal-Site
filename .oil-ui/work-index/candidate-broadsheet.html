Personal-Site (2026)

A scroll-driven descent from orbit: five sticky 100dvh scenes, a fixed altitude HUD, live GitHub feeds, and automated video clip recording.

Built with React 19, GSAP, Framer Motion, and Tailwind CSS v4. Deploys to GitHub Pages on every push to main; Playwright re-records the live site to keep all card previews strictly truthful.
